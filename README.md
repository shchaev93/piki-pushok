# Пики Пушок

Добрая пиксель-арт игра про хомячка Пушка. Статичное PWA: без сервера, без рекламы, аналитики и внешних запросов. Прогресс хранится только на устройстве.

Игра: https://shchaev93.github.io/piki-pushok/

## Как установить (для взрослого)

Играть нужно **с иконки на экране «Домой»**, а не во вкладке браузера. Тогда игра работает без интернета, а прогресс не пропадает.

- **iPhone / iPad:** открыть ссылку в **Safari** → кнопка «Поделиться» → «На экран Домой».
- **Android:** открыть ссылку в **Chrome** → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).

Важно:
- В обычной вкладке Safari данные сайта могут стереться после 7 дней без посещения, и пропадут открытые шляпки.
- У вкладки браузера и у установленной игры **разные** хранилища. Прогресс из вкладки в установленную игру не переносится.
- На iPhone игра горизонтальная. Если экран не поворачивается, выключите блокировку поворота в Пункте управления.
- Звук играет и в бесшумном режиме iPhone. Громкость регулируется кнопками сбоку, выключается звук в настройках для взрослых.

**Настройки для взрослых:** шестеренка в левом верхнем углу, открывается удержанием 3 секунды. Там звук, сброс прогресса (тоже удержанием 3 секунды), версия и состояние хранилища.

Страница всех спрайтов для проверки: `…/piki-pushok/#sprites`.

## Что есть в игре

- **Домик.** Тап по предмету: Пушок идет туда и 2-4 секунды занимается (спит, купается, туалет, батут, горка, лазилка, скакалка). Столик открывает кормление, кухня открывает готовку. Тап по Пушку: он радуется, а с гитарой играет мелодию. Сердечко в углу = сытость, кружочки = денежки.
- **Облачко** (кнопка с облаком). Облачко тянется пальцем из любого места экрана. Бабочка = денежка, пойманное яблочко Пушок сразу съедает. Раунд 60 секунд, выйти можно в любой момент, пойманное засчитывается.
- **Магазин** (кнопка с корзинкой). Цена показана кружочками-денежками. Купленное лежит в корзинке.
- **Кормление.** Еду из корзинки тянут пальцем ко рту Пушка. Семечки и блюда радуют больше всего.
- **Кухня.** 2-3 продукта перетащить в кастрюльку и помешать пальцем по кругу. Яблоко + семечки = пирожок, хлебушек + сыр = бутерброд, яблоко + морковка = салат, остальное = суп-сюрприз.
- **Гардероб** (кнопка со шкафом). Шляпки и гитары открываются по общему числу пойманных бабочек. Закрытые показаны силуэтом с полоской прогресса.
- **Голод.** Сытость падает в реальном времени, примерно за 6 часов до «просит кушать». Пушок не болеет, не убегает и не умирает: только грустит и двигается медленнее.

Все числа (цены, сытость, пороги, длительность раунда, рецепты) в `src/config.ts`.

## Разработка

```sh
npm install
npm run dev        # локальный сервер
npm test           # unit-тесты (Vitest)
npm run build      # иконки + проверка типов + сборка в dist/
npm run e2e        # Playwright: WebKit (iPhone) и Chromium (планшет), скриншоты в test-results/screens
```

На Windows тесты запускайте из каталога с заглавной буквой диска (`C:\...`), иначе Vitest может загрузиться дважды.

Деплой: каждый push в `main` собирается GitHub Actions и выкладывается на GitHub Pages (`.github/workflows/deploy.yml`).

## Устройство

- `src/config.ts`: **все** игровые числа (цены, сытость, пороги, шляпки, тайминги).
- `src/sprites/`: спрайты задаются сетками символов (`.` = прозрачный пиксель) и палитрами, их легко перекрашивать и дополнять. `pushok.ts` содержит сетку Пушка из ТЗ, а тест сверяет ее с `assets/pushok.svg` по каждой клетке.
- `src/save/`: схема сохранения с версией и миграциями (localStorage, запись после каждого изменения).
- `src/scenes/home.ts`: домик и занятия Пушка.
- `scripts/gen-icons.ts`: иконки PWA генерируются из сетки Пушка.
