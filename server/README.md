# Сервер Пушка

Голосовой разговор с Пушком: речь → Yandex SpeechKit → модель через OpenRouter → голос SpeechKit.
Без внешних зависимостей: Node 24 запускает TypeScript напрямую. Разговоры и тетрадка хранятся
на телефоне; сервер хранит только счетчики расходов за день.

## Настройки (файл `.env` рядом с `docker-compose.yml`, в git не попадает)

| Переменная | Что это |
|---|---|
| `ACCESS_CODE` | Код доступа. Тот же код вводится в игре: панель взрослых → «Разговор с Пушком». |
| `KID_NAME` | Имя ребенка, так Пушок к ней обращается. |
| `OPENROUTER_API_KEY` | Ключ OpenRouter. |
| `OPENROUTER_BASE_URL` | Адрес OpenRouter. С российского сервера — адрес релея, локально — `https://openrouter.ai/api/v1`. |
| `LLM_MODEL`, `LLM_PROVIDER` | Модель и закрепленный провайдер (по умолчанию `z-ai/glm-5.3` у `wafer/us`). Менять только после согласования цены. |
| `LLM_REASONING_EFFORT` | Уровень «размышлений» (`low`). У GLM 5.3 они обязательны и по умолчанию на максимуме — это дорого. |
| `YANDEX_API_KEY` | API-ключ сервисного аккаунта Yandex Cloud с ролями `ai.speechkit-stt.user` и `ai.speechkit-tts.user`. |
| `YANDEX_FOLDER_ID` | ID каталога: нужен, только если ключ не сервисного аккаунта. |
| `TTS_VOICE`, `TTS_ROLE` | Голос SpeechKit (API v3) и его роль. |
| `DAILY_LLM_USD`, `DAILY_VOICE_RUB` | Жесткий дневной потолок расходов (по умолчанию $0.30 и 60 ₽). При превышении сервер отвечает 429, Пушок «засыпает» до завтра. |
| `ALLOWED_ORIGINS` | Сайт игры, которому можно обращаться к серверу. |

## Личные данные — только в `data/` (в git не попадает)

- `data/seed.json` — тетрадка сказок, с которой Пушок начинает на новом телефоне.
- `data/glossary.txt` — словарик мира ребенка (любимые мультики, как их коверкает распознавание).
- `data/budget.json` — счетчики расходов за день (создается сам).

## Запуск

```sh
docker compose up -d --build     # на сервере, в каталоге с этим файлом
node src/index.ts                # локально
node scripts/eval.ts 0.30        # тестовый прогон характера на сценариях из data/, лимит в долларах
```

Тесты сервера — в общем наборе проекта: `npm test` в корне.
